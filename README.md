# Running in the Jungle
A short platformer about running around in the jungles as a weird little owl! Made in Godot by Sashreek!


<img width="1146" height="643" alt="image" src="https://github.com/user-attachments/assets/e5436bd8-e9a3-4264-9cb2-48ca90ad43ae" />

## Features
You get to parkour in-game! And also have the ability to shrink yourself to fit into the tiny cranny of a cave entrance to eventually get to the end screen.

## Why?
I made this game to get to know how the Godot game engine works. It's my first time making a platformer so it's a bit crude, but I'm pretty proud of myself for making this!

## Where do I play it?
You can find my game on itch.io!
https://reeksash.itch.io/running-in-the-jungle
